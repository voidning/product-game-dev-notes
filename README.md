# 产品与游戏开发学习笔记

记录产品与游戏开发的实用方法、学习心得和案例复盘。以中文短指南为主，围绕实际问题持续修订，帮助自己把想法做成可用、可玩的完整体验。

这里的指南是有适用条件的工作建议，不是行业定律。引用观点注明来源；个人建议与待验证判断明确区分，并在实践后更新。

## 如何积累笔记

- **新建主题**：从一个具体问题出发，参考[笔记模板](templates/note.md)，写出可以采取的行动及适用边界。短笔记可省略无关部分。
- **更新主题**：已有同主题笔记时优先修订原文，合并重复建议，保留仍然有效的边界和来源，更新日期。历史版本交给 Git 保存。
- **补充案例**：写清问题、尝试、实际观察和未验证项；通过链接关联指南，不复制整套原则。一个案例的结果不直接推广成普遍结论。
- **维护导航**：新笔记加入本页对应主题，相关笔记之间使用相对链接。文件名用简短英文，正文用中文。
